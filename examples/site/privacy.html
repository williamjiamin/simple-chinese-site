Privacy

This original local demonstration has no account, analytics, cookies, form submission or remote media. Its display button changes text in the current document and does not persist choices.

This statement describes the supplied demonstration only. It makes no claims about any existing or hosted site. A hosting service may create its own access logs if these files are later served.

Local checks

The validator reads files on the local machine. It compares canonical URLs as text and does not contact those addresses. A passing audit verifies linked privacy content exists; it does not verify legal adequacy or all runtime data flows.
